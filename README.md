# pi-sheep: why can't your agent have sweet dreams? 

![counting sheep demo](pi-sheep.gif)

## Install

```bash
pi install git:github.com/Simar-malhotra09/pi-sheep@v1.0.0
```

Then run `/reload` in pi and ask the agent to run `sleep 10`.


P.S: 'sheep' is a bit of a stretch — if you know of a better way to render it please open a PR :p
